# ZenDrift

ZenDrift implements a scalable, real-time framework for distributed applications, utilizing auto-scaling controllers and centralized managers.

With ZenDrift, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ZenDrift.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

ZenDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
